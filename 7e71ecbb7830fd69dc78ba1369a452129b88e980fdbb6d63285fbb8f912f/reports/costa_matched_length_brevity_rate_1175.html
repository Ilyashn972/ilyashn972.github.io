Total m-bits: three targets

Rate can rise while total m-bits fall, if the brief rewrite drops events. These totals ask how much predictive information each context still carries, against three different targets:

  • Original narrative — Costa’s segmented story text, scored as a preceding-context target (not the summary-vs-summary paraphrase prompt).
  • Rephrased narrative — the same events in rewritten wording, same narrative scorer.
  • Mean of rephrased summaries — average total m-bits across the held-out-excluded rephrased GPT-4o summaries on this page. That is one number per context, not a sum over targets.

Higher bar = more total m-bits for that target. Compare the brief rewrite to the length-matched summary on each group. Negative totals mean the context made the target less likely than no context at all — usually missing or distorted events.

What this page is

  1. Take the GPT-4o summary closest to 1175 characters and hold it out as a preceding context (summary_gpt4o_32_1).
  2. Take the human recall closest to that length (recall_91).
  3. Rewrite that recall more briefly with GPT-4o: drop filler only; do not add or remove facts.
  4. Pick the remaining GPT-4o summary whose original length is closest to that brief rewrite (summary_gpt4o_16_1, 775 characters).
  5. Score all four texts against every other attempt-1 GPT-4o summary (rephrased targets), and also against the original Costa narrative and the rephrased narrative, so total m-bits can be compared across three targets.

This is the same pair of recall-scale contexts as Which context predicts other Costa summaries?, plus the brevity arm and a GPT summary matched to the rewrite length. The comparison that matters for verbosity is brief rewrite vs that shorter summary, not only vs the long held-out summary. The 12-story brevity sample is a different set of recalls: recall_brevity_rewrite_report.html.

How to read the plot

Because each series uses one fixed context, rate is total m-bits scaled by a constant (1 / context length). The shape of a series matches a total-m-bits scatter; the interesting comparison is the vertical gap between series. The brief rewrite should be compared to the length-matched GPT summary (black cross), not only to the longer held-out summary (black circle).

Brevity that only drops padding should raise rate while keeping total m-bits roughly the same on all three targets. Brevity that drops events can raise rate and still lose total m-bits. That is why the totals section sits next to the rate plot.
